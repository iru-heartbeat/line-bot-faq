# LINE公式アカウント FAQ自動応答bot（オーナー様向け使い方マニュアル）

お客様からのLINEメッセージにAIが自動で回答し、答えられない質問だけオーナー様に通知するシステムです。
FAQ・メニュー・お知らせ配信は、スマホのブラウザから管理画面で編集できます。

## LINEでお客様ができること

- 営業時間・アクセス・定休日などのよくある質問 → 自動で回答
- メニュー名や料金についての質問（例:「カットはいくらですか？」）→ 自動で回答
- 「こんにちは」「ありがとう」などの挨拶・雑談 → 自然に返信
- 上記以外の質問（個別の予約調整など） → 「担当者が確認のうえ、改めてご連絡いたします」と返信し、
  内容をオーナー様にLINE通知＋記録（下記「問い合わせ履歴」で確認できます）

## 管理画面の使い方

**URL**: デプロイ先（Vercel）のドメイン + `/admin`（例: `https://〇〇.vercel.app/admin`。正確なURLはVercelのダッシュボードで確認できます）
**ログイン**: 環境変数 `ADMIN_PASSWORD` に設定したパスワードを入力します。ログインは7日間有効です。

ログイン後、画面上部のナビゲーションから以下の4ページに移動できます。

| ページ | できること |
| --- | --- |
| `/admin/faq` | よくある質問（FAQ）の追加・編集・削除。ここで登録した質問と回答が、LINEでの自動回答の元になります。 |
| `/admin/menu` | 施術メニュー名と金額の追加・編集・削除。ここを更新すると、LINEでのメニュー・料金の質問への回答にも反映されます。 |
| `/admin/inquiries` | botが自動で回答できなかった質問や、エラーで回答できなかった質問の履歴（直近20件）を確認できます。 |
| `/admin/broadcast` | 友だち全員へのお知らせを一斉配信できます。送信履歴（直近10件）も確認できます。 |

### よくある操作

- **FAQ・メニューを追加する**: 各ページ下部の「新しい〇〇を追加」フォームに入力して「追加」を押します。
- **FAQ・メニューを編集する**: 一覧内の該当カードの内容を書き換えて「保存」を押します。
- **FAQ・メニューを削除する**: 一覧内の該当カードの「削除」を押します（確認なしで即削除されるため注意してください）。
- **お知らせを配信する**: `/admin/broadcast` のフォームにメッセージを入力して「送信」を押すと、LINEの友だち全員に送信されます。

## 困ったときは

- 「お客様に返信できていない」「管理画面が開けない」などの不具合が起きた場合は、開発担当者に連絡してください。
- お客様からの問い合わせでAIがうまく回答できていない場合は、`/admin/faq` にその質問と回答を追加しておくと、次回以降は自動で回答できるようになります。
